# E-Commerce VMC - Gestión de Productos

Aplicación web funcional para gestionar productos de forma visual, aplicando conceptos de CRUD (Create, Read, Update, Delete) mediante manipulación del DOM con JavaScript vanilla.

## Características

- **Agregar productos**: Formulario para ingresar imagen (URL), nombre, descripción, precio y cupón de descuento.
- **Descuento automático**: Si se ingresa el cupón 'DISCOUNT9816', se aplica 50% de descuento al precio.
- **Visualización**: Tarjetas dinámicas que muestran todos los datos del producto y el precio final.
- **Editar productos**: Modificar datos existentes desde el formulario.
- **Eliminar productos**: Botón en cada tarjeta para borrar del DOM.
- **Interfaz atractiva**: Diseño responsive con colores vivos, usando Flexbox.
- **Sin consola**: Toda la interacción ocurre en pantalla, sin dependencias externas.

## Funcionalidades Implementadas

- **Create**: Agregar nuevos productos con validación.
- **Read**: Mostrar productos en tarjetas ordenadas.
- **Update**: Editar productos existentes.
- **Delete**: Eliminar productos del DOM.
- **Descuento**: Cálculo automático de 50% con cupón válido.
- **Responsive**: Diseño adaptable a todos los dispositivos.
